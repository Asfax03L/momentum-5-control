# OpenHeadset Control

Réglages du casque Sennheiser **MOMENTUM 5** depuis le PC, sous **Windows
11** et **Linux** (KDE Plasma, Bazzite), sans l'application mobile :
réduction de bruit, égaliseur, scènes, batterie, Multipoint. Logiciel libre
(MIT ou Apache-2.0), en Rust, avec une interface native par système.

::: avertissement
Projet **non officiel**, sans lien avec Sennheiser ni Sonova. Seuls les
réglages validés sur le casque sont modifiés ; ni mise à jour du
micrologiciel, ni réinitialisation d'usine.
:::
