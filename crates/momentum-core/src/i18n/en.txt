Bienvenue
Welcome

OpenHeadset Control règle le Sennheiser MOMENTUM 5 depuis ce PC : réduction de bruit, égaliseur, scènes, batterie. Projet non officiel, sans lien avec Sennheiser ni Sonova. Seuls les réglages documentés sont modifiés ; le reste est en lecture seule.
OpenHeadset Control adjusts the Sennheiser MOMENTUM 5 from this PC: noise cancelling, equalizer, scenes, battery. Unofficial project, not affiliated with Sennheiser or Sonova. Only documented settings are changed; everything else is read-only.

Bluetooth
Bluetooth

Appairage
Pairing

Appairez le casque avec ce PC dans les paramètres Bluetooth du système (mode appairage : voir la notice du casque). OpenHeadset Control n'appaire rien lui-même : il trouve ensuite le casque tout seul.
Pair the headphones with this PC in the system Bluetooth settings (pairing mode: see the headphones' manual). OpenHeadset Control does not pair anything itself: it then finds the headphones on its own.

This interface uses Windows App Runtime 2: it is installed, since this window is showing. The installer checks it; after reinstalling Windows: winget install Microsoft.WindowsAppRuntime.2.

With Multipoint, the headphones stay connected to two devices at once, for example two PCs or a PC and a phone. OpenHeadset Control can run on each PC. Turning Multipoint off disconnects the other device.
