# Illustration de présentation

`casque-illustration.png` est une illustration originale générée avec
ImageGen le 28 octobre 2026 pour le bandeau de l'accueil WinUI.

Elle représente un casque noir générique, sans marque ni texte. Ce n'est
pas une photographie officielle ni une représentation technique exacte du
MOMENTUM 5. Le modèle et les états affichés proviennent du service ; l'image
n'est qu'une illustration de présentation. Le nom accessible le précise.

Le fond transparent est conservé pour les thèmes clair et sombre. Le PNG
est intégré à l'exécutable : aucun téléchargement n'a lieu à l'ouverture de
l'interface et aucun fichier utilisateur n'est nécessaire.
